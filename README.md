
# Nombre de tu E-commerce
Mi proyecto ecommer en React

## Descripción
Proyecto de e-commerce desarrollado con React y Vite, correspondiente al curso de desarrollo web / frontend de Coderhouse. La aplicación sienta las bases estructuradas para el desarrollo del proyecto final.

## Tecnologías Utilizadas
- **React 19**
- **Vite**
- **JavaScript (ES6+)**
- **HTML5 / CSS3**
